# Sentiment Analysis on Product Reviews

## Project Overview
This project focuses on analyzing customer product reviews using Natural Language Processing (NLP) and Machine Learning techniques.

The main objective is to identify the sentiment expressed in customer reviews and understand whether the feedback is positive or negative.

## Objectives
- Analyze customer product reviews.
- Perform text preprocessing.
- Apply NLP techniques.
- Classify customer sentiments.
- Understand customer opinions and feedback.

## Dataset
This project contains two dataset files:

- `train_reviews.csv` – Training dataset.
- `test_reviews.csv` – Testing dataset.

## Technologies Used
- Python
- Machine Learning
- Natural Language Processing (NLP)
- Pandas

## Project Outcome
The project aims to classify product reviews based on their sentiment and help understand customer feedback.
